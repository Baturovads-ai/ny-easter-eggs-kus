# Новогодние пасхалки КУС (демо)

Три микровзаимодействия для кабинета участника сделки: гирлянда прогресса, замёрзший экран (стирается варежкой), шаг с праздничной кнопкой. Демо на чистом HTML/CSS/JS, открывается через GitHub Pages.

Фоны экранов — скриншоты макетов. Тексты поздравлений и подсказка — плейсхолдеры.
